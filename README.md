# Loan Approval System ('mx7.py')

A simple python script built to practice **nested conditional logic ('if-else' statements )**.

##How it works
The program screens loan applications using two layers of verification:
* **Age Check: ** Requires the user TO BE **21 or older**.
* **Salary Check: ** Requires a salary of **36,000 or more** (only checked if the age requirement passes)>

## Concepts Learned
*  Converting user input into integers('int(input())').
*  Nesting 'if' blocks to create multi-step evaluation rules.
